# Source Code Rubric

Source: Project_18Nov26_rubrics on UM Learn

| Criterion | Points | What I look for |
|---|---|---|
| Pathway Implementation | 25 | Custom module, loss, or embedding implemented correctly; a substantive structural or mathematical divergence from the original repository |
| Reproducibility | 20 | README steps run end-to-end without debugging; dependencies listed; seeds fixed; reported results can be regenerated |
| Data Pipeline & Evaluation Integrity | 15 | Correct train/validation/test splits with no data leakage; metrics implemented correctly |
| Baseline & Fair Comparison | 10 | Unmodified baseline trained on the same data, splits, and training budget |
| Ablation & Sensitivity Experiments | 15 | Scripts or configurations that regenerate the ablation study and the Empirical Sensitivity Map |
| Attribution | 5 | Unmodified and custom files clearly marked; original sources and licenses credited |
| Code Quality & Documentation | 10 | Organized, readable, well-commented code |
| **Total** | **100** | |

Code whose contribution is limited to configuration, hyperparameter, or file path changes may receive a failing grade regardless of other scores.
